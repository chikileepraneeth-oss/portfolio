# Portfolio

Personal portfolio of Praneeth Chikile, AI/ML Engineer focused on agentic AI for robotics.

It is a single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no frameworks and no build step).
Netlify deploys it from this repository on every push to `main` (see `netlify.toml`).

## Run locally

```bash
python -m http.server 8000
# then open http://localhost:8000
```
